Design notes (o que mudou e por quê)

  • Bots como home: substituir o Chat como start destination. Tu abre o app e vê teus bots, não uma tela de menu.
  • Bot = contato (Telegram-style): cada linha tem avatar, nome, presença (online/offline), última mensagem de QUALQUER autor (não só user), badge de não-lido, e timestamp. Ring azul no bot ativo (PM2-D).
  • Chat é destino, não menu: tap num bot → empurra a tela de chat. Composer contextual "Message research" (PM2-B). Bot-to-bot deliveries aparecem com badge "From Hermes" no topo (PM1). Tool cards inline tipo "Created routine" (PM2-A).
  • Atividade como feed: substitui Bot DMs como home secundária. Funde "o que rolou" entre bots + cron + tuas sessões recentes, num feed cronológico com autor destacado.
  • "Mais" mantém o drawer antigo: 24 telas (Cron, Files, Analytics, Kanban, Settings, etc) continuam acessíveis, mas competem com bots pela atenção. Bot DMs screen vai pra dentro do "Mais" como item "Bot DMs (archive)" — visualizador passivo.
  • Inspirado no Spacek: paleta escura profunda, avatares coloridos vibrantes, hierarquia clara. Adaptei o que faz sentido pra mobile (bottom nav em vez de sidebar).
  • Group chat (PM3) não incluído: próxima campanha depois de validar essa reorganização.
